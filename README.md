# Dragon

## Kirasa, dragon lame-pétale

`index.html` : un dragon dessiné et animé en Canvas, inspiré d'une créature Roblox
(corps lilas et blanc, marques rouge sang, contours noirs, collerettes en pétales, ailes en lames).

Ouvre `index.html` dans un navigateur, puis choisis une animation :

| Touche | Animation | Ce qui bouge |
|---|---|---|
| `1` | Repos | Respiration, battement lent des ailes, clignement des yeux, collerettes qui frémissent, queue qui balance |
| `2` | Marche | Ailes repliées, pattes en alternance, balancement du corps, le sol défile |
| `3` | Vol | Grands battements d'ailes, pattes rentrées, le dragon s'élève |

Les transitions entre animations sont fluides (interpolation de la pose).
